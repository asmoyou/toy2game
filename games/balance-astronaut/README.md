# 平衡太空人

使用 TypeScript、Three.js 和 cannon-es 开发的同屏 3D 平衡游戏。优先支持 iPad 触控，并支持桌面和手机。

## 游戏规则

本作采用以下数字版规则：

- 2 至 4 个同屏席位，可分别设为真人或电脑，默认一位真人与一位电脑。
- 从空盘开局，四圈由内向外逐级降低，共 48 个停靠位。盘面和碰撞体使用同一组尺寸、高度配置。
- 轮流放置模式每回合放 1 位；骰子挑战模式掷 1 至 6 点，按点数逐一放置，剩余空位不足时以空位数为准。
- 点击或轻触空位直接放置，无需确认按钮；也可在停靠位列表中直接点选放置。每次放置最多观察 8 秒有效对局时间，提前稳定就继续；超时仍无人倒下也会推进回合。骰子模式先完成当前玩家的剩余次数，再换人。观察期间显示倒计时并锁住重复放置，拖动、多指和取消的手势不会放置队员。
- 有队员倒下或滑落时，最后放置的玩家失败，其余玩家获胜；超时换人后、下一位尚未放置前发生的滑落仍归上一位。全部停靠位站满且通过观察（稳定或超时无人倒下）时，全员共同获胜。
- 结算提供可选的趣味转盘，内容是本地聚会的小动作，不影响胜负。它是数字版改编，不照搬图片中无法辨认的转盘内容。
- 配置使用并列的真人／机器人按钮，取消草稿不改变当前对局。下方待命队员的数量和颜色对应已生效的队伍配置，所有队员质量相同。

平台使用可倾转的中心支点约束，四层均匀薄壳的几何形状决定重心和转动惯量。没有自动回正弹簧，也不按预定手数或平台角度判负；重力、力臂、接触摩擦与刚体姿态决定倾斜、滑落和倒下。角速度阻尼只消耗运动能量，不把倾斜平台拉回水平。提前稳定的判定同时检查持续 0.75 秒的位姿变化和支点周围的剩余重力矩，位移容差 0.24 mm、转角容差约 1.15°，减少接触计算的小幅抖动造成的等待。8 秒超时是数字版的节奏兜底，不代表物理世界已经完全静止；不会扶正或冻结刚体，后续仍按实际倒下、滑落判负。

当前假设平台质量 180 g、每位队员 2.5 g、接触摩擦系数 0.38；1 场景单位对应 2 cm，使用 1/120 秒固定步长。上述尺寸和参数是建模估值，并非参考玩具的实测值，因此不能声称一比一物理标定。旧版“标准／灵敏”设置已移除，旧偏好会忽略该字段。规则、物理、画面和 UI 分别位于 `game.ts`、`physics.ts`、`scene.ts` 和 `main.ts`。

设置保存在 `balance-astronaut-preferences-v1`。刷新重新开局，不保存瞬时刚体世界。暂停、打开弹窗和切到后台会暂停对局计时（包括平衡观察倒计时）、电脑行动及物理模拟。

## 运行与验证

在仓库根目录执行，统一服务的实际地址以终端为准：

```sh
npm install
npm run dev
npm test --workspace games/balance-astronaut
npm run build
npm run test:e2e
SITE_URL=http://localhost:5173/ npm run test:games
```

统一开发服务只监听 5173，所有登记游戏与热更新共用该端口。详细浏览器验证使用 `GAME_URL=http://localhost:5173/games/balance-astronaut/ npm run test:browser --workspace games/balance-astronaut`，可用 `CHECK_WEBKIT=1` 加测 WebKit；首次需要 `npx playwright install webkit`。运行生产 `test:e2e` 前先停止开发服务，生产预览也使用 5173，验证后再启动开发服务。

开发环境的 `window.__balance` 提供规则状态和场景诊断；生产构建不暴露此接口。设备模拟不等同于真实 iPad 硬件测试。

开发服务运行时，可在根目录执行 `GAME_ID=balance-astronaut SITE_URL=http://localhost:5173/ npm run covers`。脚本通过合法放置动作推进到对局中途，截取实际场景作为大厅封面，地址需替换为当前开发服务地址。

所有 3D 模型、图案和声音由本游戏代码生成；不依赖远程素材。中文字体使用本地加载的 Noto Sans SC，遵循 SIL Open Font License，许可证位于 `public/fonts/noto-sans-sc-OFL.txt`。封面截自实际游戏。
