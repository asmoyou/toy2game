# 青蛙吃豆豆 · Frog Feast

把屏幕放在桌上，按住自己的青蛙，一起抢光盘中的彩豆。独立的 TypeScript + Three.js + cannon-es 游戏，支持 2–4 个同屏席位、机器人和全电脑对战。

## 参考来源与规则依据

- 外观参考：用户提供的仓库根目录 `青蛙吃豆.png`。可以观察到蓝色圆盘、朝向中央的绿／蓝／黄／红四只青蛙、按压杆、彩色球和外侧收豆盘。参考图只作建模依据，不作为游戏场景或发布封面。
- 图片无法确定原玩具的完整规则、球数、弹簧行程或原厂计分方法。本实现不声称逐项复刻原厂规则。
- 用户已确认数字版规则：2–4 个真人或机器人席位同时按压抢豆，长按连续动作，每颗 1 分，抢完后最高分获胜。

## 实际玩法与数字版改编

- 默认四个席位：1 号绿蛙由真人操作，2 号蓝蛙、3 号黄蛙和 4 号红蛙由机器人操作。所有席位均可配置；两席时为相对的绿蛙和蓝蛙。未启用的青蛙收起按压杆，不参与抢豆。
- 每局 60 颗等值彩豆。点击「开始抢豆」或真人的吃豆按钮进入 3 秒倒计时；倒计时结束后所有青蛙可同时行动。
- 轻触 3D 青蛙／按压杆吃一次，按住下方所属玩家的大按钮或键盘 A / L / Z / M 连续吃豆。长按不会比快速点按更慢，每次完整伸头、合嘴、收回约 0.7 秒。
- 豆子使用 cannon-es 球体碰撞与固定步长模拟。平面运动近似盘中滚动，盘底施加周期性的轻微倾斜加速度，使剩余豆子继续滚向可吃区域。这是数字版的自动摇盘功能，避免最后几颗停住；没有随机加分或预设胜负。
- 嘴闭合期间，只有实际位于嘴内的球才被取走，每次最多吃 3 颗。各色豆子等值，分数及收豆盘会同步增加。机器人也通过同一合法动作入口，遵守相同冷却和嘴部范围。
- 全部豆子吃完即结算；最高分并列则共同获胜。结束后可「再来一局」或「换个阵容」。不设时限和额外道具。
- 设置先编辑草稿，取消不影响当前局，确认按草稿开新局才应用。减少人数后再增加会保留本次编辑中隐藏席位的选择；提交后未启用席位清为空闲，之后新增席位默认真人。
- 「新的一局」沿用当前设置，有进度时先确认；未开始或已结束则直接重新布置。音效与全屏即时生效。
- 拖动空白场景旋转视角，双指／滚轮缩放；视角工具提供旋转和复位。拖动、多指和取消的手势不会吃豆。多人同时触控请使用下方的独立吃豆按钮。
- 暂停、阻断弹窗、页面后台及失焦会冻结倒计时、物理与电脑操作，并清除按住状态，恢复后需重新按压。
- 偏好保存在 `frog-feast-preferences-v1`，包含版本及结构校验。刷新重新布置，不尝试恢复瞬时物理世界；已保存的阵容与音效保持。随机源可传入种子，以重现布球和电脑调度。

## 运行与验证

从仓库根目录执行：

```sh
npm install
npm run dev
npm test --workspace games/frog-feast
GAME_URL=http://localhost:5173/games/frog-feast/ npm run test:browser --workspace games/frog-feast
GAME_ID=frog-feast npm run covers
npm test
npm run build
# 先停止开发服务；生产测试也使用 5173，结束后关闭临时预览
npm run test:e2e
```

开发地址为 `http://localhost:5173/games/frog-feast/`。统一服务只监听 5173，使用 Ctrl+C 停止。独立入口可用 `npm run dev --workspace games/frog-feast -- --port 5173 --strictPort`，不要与统一服务同时运行。非根路径通过 `SITE_BASE=/toy2game/ npm run build` 验证。

详细浏览器测试覆盖真实输入、完整结算、设置草稿、重开、暂停与后台、全屏能力／失败反馈、存储、相机手势、画布像素和多尺寸截图；`CHECK_WEBKIT=1` 可加测 WebKit 的 iPad 横竖屏模拟，首次需 `npx playwright install webkit`。开发诊断 `window.__frog` 仅在开发构建中提供。设备模拟不代表真实 iPad 硬件测试。

## 资源与限制

模型、表面图案、青蛙图标与声音均由本游戏代码生成。封面截自实际 3D 游戏。中文字体为本地 Noto Sans SC，使用 SIL Open Font License，许可证保留在 `public/fonts/noto-sans-sc-OFL.txt`。图标使用 lucide。不依赖远程素材、账号或后端，不支持异地联机；小屏多人游玩建议横放平板或使用键盘。全屏入口仅在浏览器支持且权限允许时显示，兼容成对的旧版 Safari 接口。
