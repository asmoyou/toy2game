# 小兔闯关 · Little Rabbit

Three.js 三维网页棋盘游戏。山丘、胡萝卜、兔子、木桥和植物均为程序化三维模型，不依赖远程模型服务。

面向 3 至 12 岁儿童，优先适配 iPad 网页横屏游玩，同时支持竖屏。主要操作采用大触控目标，可点卡牌翻牌、点编号兔子前进。默认手动视角，支持旋转、双指缩放和平移；跟随可选，手动拖动会退出跟随。顶部仅在浏览器支持且允许页面全屏时显示全屏按钮，兼容标准与旧版 Safari 接口；进入、退出全屏不会重置对局或视角。

## 运行

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。同一 Wi-Fi 下的 iPad 或手机可以使用终端显示的局域网地址访问，电脑需保持服务运行。

```sh
npm run build
npm run preview
```

`dist/` 是可部署到静态网站托管服务的生产文件。网站使用浏览器本地存储保存进度，无需后端或 API 密钥。字体与图片也包含在项目中。

## 玩法

- 每局可配置 2 至 4 位玩家，并单独指定每一位为真人或电脑，也可让电脑自动对战。
- 顶部“游戏设置”独立配置人数、各席位的“真人／机器人”和雷云天气。人数及席位均使用分段选择，新增席位默认真人；同一次设置中减少人数再增加，会保留暂时隐藏席位的选择。关闭弹窗会放弃修改，点击“按此设置开始新局”后才应用并保存。默认仍为一位真人和两位电脑，小兔子允许首位及全部席位设为电脑。
- 顶部“新的一局”沿用当前人数、阵容和天气重开。有行动、探索徽章或落雷记录且尚未结束时先确认，“继续这局”或关闭弹窗均保留当前进度；未产生进度或已结束时直接重开。结算后的“再来一场冒险”同样沿用当前配置，“换个阵容”才进入设置。音效和全屏随时生效，不触发重开。
- 每队三只兔子。所有玩家共用一副 52 张牌：前进 1 格 18 张、2 格 16 张、3 格 10 张、胡萝卜机关卡 8 张。机关卡占约 15.4%，采用普通随机洗牌，仍允许偶然连抽；弃牌也属于同一个公共牌堆。
- 卡背、卡面与玩家颜色对应，并显示玩家名字。
- 地图包含 28 格外围草地和 27 格山路，共 55 格；从蘑菇营地出发，绕过池塘和风车花园，再登上中央山丘。
- 每局随机生成 8 个机关或道具，每种 2 个，拉开间距；放大的模型位于格子内，兔子占格后隐藏模型，避免重叠。开局后布局保持固定。
- 点蘑菇会弹跳，点池塘会出现涟漪与跃起的小鱼，点风车会加速转动。三处探索可收集花园徽章，重复触发动画不会重复领取徽章，也不消耗回合。
- 停在星星格上可收集星星，每颗星星只能被领取一次；收集奖励不改变移动步数。
- 卡牌格数固定，不受其他兔子占位影响；之后单独结算机关引发的移动。同格兔子并排显示，腹部号码对应选择栏。
- 选择兔子时用绿色圆环预览路线，危险落点保留红色提示。
- 机关切换六处陷阱的开合，木桥会翻起，没有护盾的同格兔子一起掉落；护盾会将兔子送到后方最近的安全格。
- 任意一只兔子率先登顶，或成为最后存活的队伍，即获胜。获胜兔子会坐到中央胡萝卜顶部的叶环宝座上。
- 结算包含获胜兔子的立体头像、星星礼花、排名和对局统计，可以返回棋盘查看，也可再次打开结算。
- 支持三维点选棋子、相机旋转与缩放、音效、暂停、对局记录和刷新续玩。

| 机关或道具 | 实际效果 | 配套反馈 |
| --- | --- | --- |
| 弹簧跳台 | 额外前进 3 格，可以连到下一处机关 | 弹簧压缩、腾空跳跃、绿色光圈与上升音效 |
| 逆风陷阱 | 后退 2 格 | 风车加速、风痕、后退数字与风声 |
| 滑梯陷阱 | 退回当前路段的安全起点 | 滑梯模型、沿路滑行、紫色轨迹与下降音效 |
| 泡泡护盾 | 抵挡一次地洞、逆风、滑梯或雷击，每只兔子最多一层 | 兔子身上的透明护罩、抵挡提示和破泡反馈 |
| 胡萝卜机关 | 切换地洞和木桥，触发掉落或护盾营救 | 胡萝卜蓄力光环、机械声、洞口亮光、翻桥与掉落动画 |

预览中绿色是卡牌路线，金色是弹簧助力，紫色是陷阱回退，蓝色是护盾保护。所有机关动画结算后才开放下一次操作。电脑对手会考虑最终落点、陷阱和护盾。

雷云从开局就存在，并持续沿随机路点平滑巡游，通常每 6 至 12 秒向经过的位置落雷。空地只播放效果；落在有兔子的格子会造成一回合眩晕，同格兔子一起受影响，护盾可以抵挡。当前队伍被击中时禁用本次待执行回合，其他队伍则禁用其下一个回合。重复雷击不会延长已有眩晕。全队无法行动时可休息一回合，恢复后继续。暂停、打开设置或切到后台时天气计时暂停，兔子移动期间会延后落雷判定，但乌云继续移动。

这是一款参照玩具形象改编的独立规则版本，并非实体产品的官方复刻。目前的多人模式为同屏游戏，尚未接入异地联网房间。[在线试玩](https://games.asmo.top/games/rabbit-trap/)。

## 实现

- `src/scene.ts`：Three.js 几何建模、光照、相机、鼠标拾取和 GSAP 动画。
- `src/world.ts`：外围路线、山路、星星与场景位置配置。
- `src/weather.ts`：持续巡游轨迹、随机天气计时和落雷位置。
- `src/game.ts`：boardgame.io 管理回合、洗牌、合法操作与胜负；包含电脑决策。
- `src/App.tsx`：React 中文界面、电脑调度、存档与对局设置。
- `src/style.css`：桌面和移动端布局。
- `src/touch.css`：iPad 横竖屏、大触控目标和探索操作区。

存档保留游戏引擎完整状态，包括随机数状态，因此刷新不会改变下一次洗牌结果。页面动画与规则状态分离，移动过程中会锁定操作。

旧版 27 格存档会迁移到扩展地图上对应的山路位置，保留兔子位置、出局状态和获胜状态。已有对局保留布局，新开一局生成稀疏随机布局。旧牌组在下一次抽牌时更新为 52 张。玩家配置、道具、眩晕、天气轨迹、星星和探索徽章都会自动保存。

## 验证

```sh
npm test
npx playwright install webkit
npm run test:e2e
npm run build
```

通用浏览器测试使用已安装的 Google Chrome，iPad 测试使用 Playwright WebKit 的触控设备模拟，覆盖 1180×820、1024×768 和 820×1180 视口。模拟测试不等同于真实 iPad 硬件测试。若机器没有 Chrome，可通过 Playwright 安装 Chromium 并调整 `playwright.config.ts` 的 `channel`。截图输出到 `artifacts/`。测试专用的 `window.__rabbit` 只存在于开发模式，生产构建不会暴露该接口。

`boardgame.io` 的安装依赖包含旧版服务器和调试组件，因此 npm 仍会报告间接依赖的安全公告。本项目只部署静态客户端，不运行这些服务器组件；增加联网后端前需重新评估并升级相关依赖。
