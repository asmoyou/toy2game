# 翻棋对对碰 · Flip & Match

薄荷绿八角棋盘上的记忆配对游戏，支持 2–4 个同屏真人或机器人席位。

## 参考来源与规则依据

- 外观依据为用户提供的根目录 `翻棋对对碰.png`：可以观察到绿色八角棋盘、黄色圆形棋子、动物与水果图案、四角收纳槽，以及四边的黄色星星翻棋棒。商品图只作建模参考，不用于生产场景或封面。
- 图片未提供原厂规则，不能确定棋子总数、棒子的具体使用步骤、成功后是否连翻或原厂计分方式。数字版采用下述记忆配对规则，不宣称是原产品官方规则。
- 开局全部背面朝上；每回合依次翻两枚。相同则收走，得 1 分并继续翻；不同则展示片刻后盖回，换下一位。全部配完后分数最高者获胜，并列最高则共同获胜。

## 数字版改编

- 默认 24 对（48 枚），可选 12 对（24 枚）；棋面为重新绘制的动物与水果，不复制商品贴纸。点击棋子代替使用实体翻棋棒。
- 默认 1 号真人、2 号普通机器人，所有席位均可配置，支持全电脑对战。新增席位默认真人。
- 机器人提供轻松、普通、困难、完美记忆四档，默认普通，当前难度适用于本局全部机器人。前三档会漏记、遗忘和发生回忆失误；每个机器人独立记忆所有玩家公开翻过的棋子，不读取未翻棋子的图案。洗牌、观察和选择均由种子重现。
- 不限时；每对 1 分。翻棋和收棋有动画，结算期间禁止重复翻动。暂停、设置、规则、重开确认及页面隐藏时暂停计时、动画和电脑操作。
- 人数、席位、棋盘大小和机器人难度先编辑草稿，取消不影响本局；确认按草稿开始新局。独立的「新的一局」沿用已生效配置与难度，有进度时须确认。全部真人时难度选择不可用，草稿选择会保留，重新加入机器人后生效。
- 沿用 `flip-match-save-v1` 与 `flip-match-preferences-v1` 存储键，内容升级为版本 2，保存难度、种子和合法动作记录。刷新重放记录恢复各机器人记忆及下一次决策，暂停或刷新不会重新抽取失误。版本 1 的旧局保留洗牌结果、得分和翻棋进度，迁移为普通难度，并按原公开记录重建有限记忆；旧偏好也默认普通。损坏、未知版本或不可用的存储不阻止开局。

## 机器人难度

| 难度 | 最多记住的位置 | 每次公开翻棋的记入概率 | 每次选择的回忆失误概率 |
| --- | --- | --- | --- |
| 轻松 | 6 枚 | 60% | 20% |
| 普通（默认） | 12 枚 | 80% | 12% |
| 困难 | 20 枚 | 95% | 4% |
| 完美记忆 | 全部（最多 48 枚） | 100% | 0% |

记忆按最近成功记入的顺序更新，容量满时忘掉最早一枚；已收走的棋子会从记忆中移除。当前翻开的第一枚仍然可见，不依赖长期记忆。正常回忆时优先配对记得的位置，再探索不记得的棋子；回忆失误时从合法棋子中选择，仍有可能碰巧配对，所以表中的失误概率不等于配对失败率。

完美记忆不保证每局必胜，仍受未知棋子和回合顺序影响。前三档是游戏强度参数，不宣称对应儿童、普通成人或专业选手的认知水平；各档思考与展示时间一致。

## 操作与实现

点击或轻触棋子翻面；拖动空白旋转，双指或滚轮缩放，可旋转、俯视和复位。下方「棋子列表」提供带编号的大按钮，适合小屏与键盘选择。全屏入口按浏览器能力及权限显示，兼容成对的旧版 Safari 接口；失败给出提示，切换不改变对局或相机。

Vite + 严格 TypeScript + Three.js + boardgame.io。规则与可复现随机位于 `src/rules.ts`，引擎与定时调度在 `src/game.ts`，程序化模型与绘图在 `src/models.ts`、`src/art.ts`，场景与输入在 `src/scene.ts`，界面与设置在 `src/main.ts`。

## 运行与验证

在仓库根目录执行：

```sh
npm install
npm run dev
npm test --workspace games/flip-match
GAME_URL=http://localhost:5173/games/flip-match/ npm run test:browser --workspace games/flip-match
GAME_ID=flip-match npm run covers
npm test
npm run build
npm run test:e2e
```

开发诊断接口 `window.__flip` 仅在开发模式提供。`CHECK_WEBKIT=1` 可加测 WebKit 设备模拟，首次需安装对应浏览器。截图保存在被忽略的 `artifacts/flip-match/`。生产测试前关闭开发服务；子目录部署使用 `SITE_BASE=/toy2game/` 构建并验证。

专项浏览器脚本支持 `CHECK_ENGINE=chrome` 或 `CHECK_ENGINE=webkit` 选择引擎，`CHECK_CASE` 可按测试名称的正则表达式筛选；全屏脚本单独执行 `CHECK_WEBKIT=1 node games/flip-match/tests/fullscreen-check.mjs`。
