# 企鹅敲敲敲

适合 iPad Safari 的本地同屏多人 3D 游戏。使用 Three.js 渲染，使用 cannon-es 模拟冰块和企鹅的刚体运动。

## 启动

需要 Node.js 22.18 或更新版本。

```sh
npm install
npm run dev
```

终端会显示 Local 和 Network 地址。电脑浏览器打开 Local 地址；iPad 与电脑连接同一 Wi-Fi，在 Safari 中打开 Network 地址。电脑需要保持运行，端口占用时以终端实际显示的地址为准。

## 玩法

- 2～4 个席位共用一个屏幕，轮流点一块冰，每人每轮只能敲一下。在设置的“玩家阵容”中，可将玩家 2～4 切换为机器人。
- 每局固定由玩家 1 开始，包括重新开局、修改阵容和结算后的再来一局。
- 单指拖动或鼠标拖动可旋转视角，双指可缩放并旋转；右下角提供左右旋转、俯视和恢复默认视角。拖动、多指操作和取消的手势不会被当成敲击。
- 机器人会参考企鹅的位置和连接受力选择冰块，思考后自动敲击；机器人回合无法手动代敲。打开弹窗或将网页切入后台，会暂停机器人和物理模拟。
- 每块冰从开局起都是有质量的动态刚体，持续受到重力影响。冰块之间、企鹅与冰面、冰块与边框均有接触摩擦和碰撞。
- 冰块间以有限夹紧摩擦和抗扭能力的可断裂连接近似拼接结构。重力载荷、企鹅重量或敲击冲量超过连接能力时，冰片会滑移、倾斜和脱落；仍有少量路径连接边框的冰桥也可能坍塌。
- 多处支撑可以共同承重。连接接近承重上限时仍能保持夹持，出现持续过载和实际滑移才会脱落；短暂敲击震动可以恢复，严重分离的冰片仍会立即断开。
- 夹持需要来自对侧或多个方向的挤压。失去对向接触的冰块会自然脱落，单靠一侧边框不能悬空；机器人会考虑敲击是否导致相邻冰块失去挤压。
- 敲击后，弹性震动沿仍连接的冰块传递，连接越少或受力越大，回摆越明显，并自然衰减。画面会适度放大细微位移以便在 iPad 上看清，企鹅随支撑面移动并张开翅膀保持平衡。
- 企鹅通过真实刚体接触站在冰面上，失去支撑后掉下去；造成掉落的当前玩家输，其余玩家获胜。
- 企鹅会根据附近支撑、受力、倾斜和冰块数量表现出开心、警觉、受惊或慌张，落水后会浮起划水。结算展示获胜玩家、敲击次数和用时，并播放彩纸庆祝动画。
- 场景保留白色冰面和四脚支撑架，仅在架子下方设置不规则破裂冰洞与海水。中央落下的冰块会溅水、漂浮，洞外的冰块会落在白色冰面上。
- 敲击后会等企鹅和剩余冰块都稳定、连接不再过载后再换人，避免连锁坍塌尚未结束就把失败算给下一位玩家。
- 设置中可选择 37 块或 61 块冰场，并开关音效。人数、机器人席位、冰场和音效偏好保存在本机。
- 落水次数在当前页面会话内累计。更换人数或机器人席位会清零次数。

物理参数按游戏比例调校，属于可实时运行的刚体近似模型，并非真实材料的实验标定。

## 构建与验证

```sh
npm run build
npm run preview
npm test
npm run test:balance
```

`dist/` 可部署到静态网站服务。游戏模型和声音由代码生成；字体优先使用 Noto Sans SC，加载失败时自动使用系统中文字体。

启动开发服务器后，运行浏览器验证：

```sh
GAME_URL=http://localhost:5174 npm run test:browser
GAME_URL=http://localhost:5174 CHECK_WEBKIT=1 npm run test:bots
GAME_URL=http://localhost:5174 CHECK_WEBKIT=1 npm run test:experience
```

需要本机安装 Google Chrome。验证包含桌面、iPad 横竖屏、手机横竖屏的截图、画布像素检查、真实触摸、轮换、掉落判负、重开、设置和持久化。机器人测试另覆盖输入锁定、暂停、重开时取消计时、三个机器人连续出手与屏幕旋转。截图输出至 `test-results/`。

`npm test` 包含完整冰面承重、多点支撑局面连续 21 手、窄冰桥在有无重力下的对照、摩擦不足时的坍塌，以及两种冰场共六组固定随机种子的完整对局。`npm run test:balance` 输出这六组对局的手数和坍塌统计，便于比较参数调整。

可使用 `CHECK_WEBKIT=1` 同时运行 WebKit 验证；首次使用先执行 `npx playwright install webkit`。
